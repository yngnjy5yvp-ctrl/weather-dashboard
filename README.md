# Weather Dashboard

A responsive web application that displays current weather conditions and a 5-day forecast using a public API.

## Technologies Used
- Frontend: React.js, CSS3
- API: OpenWeatherMap
- Deployment: GitHub Pages

## Features
- Current weather for any location
- 5-day forecast
- Temperature unit conversion (°F / °C)
- Clean, mobile-friendly interface

## Installation
1. Clone the repository
2. Run `npm install`
3. Create a `.env` file with your API key
4. Run `npm start`

## Usage
Search for a city name to view live weather data.
